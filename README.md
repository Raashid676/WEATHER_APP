# 🌦️ Weather App

A modern weather application built with **React.js** and **Vite** that provides real-time weather information using the **OpenWeatherMap API**. Users can search for any city and instantly view the current temperature, humidity, wind speed, and weather conditions.

## ✨ Features

* 🔍 Search weather by city name
* 🌡️ Real-time temperature in Celsius
* 💧 Humidity information
* 🌬️ Wind speed display
* 🌤️ Dynamic weather icons based on current conditions
* ⌨️ Press **Enter** or click the search icon to search
* 📱 Clean and responsive user interface
* 🌍 Default weather displayed for Srinagar on page load

## 🛠️ Tech Stack

* React.js
* Vite
* JavaScript (ES6+)
* CSS3
* OpenWeatherMap API

## 📂 Project Structure

* React functional components
* React Hooks (`useState`, `useEffect`)
* Fetch API for HTTP requests
* Environment variables for API key security

## 🚀 Getting Started

1. Clone the repository.
2. Install dependencies:

   ```bash
   npm install
   ```
3. Create a `.env` file in the project root and add:

   ```env
   VITE_APP_ID=YOUR_OPENWEATHERMAP_API_KEY
   ```
4. Start the development server:

   ```bash
   npm run dev
   ```
